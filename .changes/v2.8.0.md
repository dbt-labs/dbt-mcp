## v2.8.0 - 2026-10-12
### Enhancement or New Feature
* Tools declare their inputs and access requirements. Named context mappers replace positional and type-based injection; implementations read resolved targets from context. HIDE omits unused selectors, and value mappers inject known selections. FastMCP generates the schema and validator and rejects extra inputs before mapping. Hosts resolve and authorize targets while building context; ordinary mapper inputs also reach the implementation unchanged. One registry replaces separate single-project and multi-project tools. Discovery fetchers hold resolved configuration. list_jobs requires a project or selected environment and includes staging; account-wide listing is removed. AdminApiConfig.environment_id replaces prod_environment_id. Hosts enforce ownership checks for supplied job/run IDs.
### Under the Hood
* Declare pydantic, pydantic-core, anyio and pyarrow as direct dependencies, since the code imports them directly
### Bug Fix
* Limit Flight SQL prepare calls to 60 seconds and run query_metrics over the Semantic Layer GraphQL API when the Flight SQL connection fails
