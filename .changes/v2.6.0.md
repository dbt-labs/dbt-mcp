## v2.6.0 - 2026-10-06
### Enhancement or New Feature
* Tell the user how to re-authenticate when a warehouse query fails because the OAuth connection expired, with a link to their credentials page in dbt platform (query_metrics, get_dimension_values, get_metrics_compiled_sql and execute_sql)
* Resolve relative DBT_PROJECT_DIR, DBT_PROFILES_DIR and DBT_PATH values to absolute paths at startup, so they no longer depend on the directory the server is launched from
### Under the Hood
* Simplify the integration test workflow: fork PRs run on pull_request_target and wait for environment approval on every commit, instead of failing a separate gate and requiring the ok-to-test label
* Pin go-task and d2 versions in CI and consolidate go-task installation into a reusable composite action
### Bug Fix
* Allow up to 10 seconds of clock skew when verifying dbt Platform OAuth access tokens so freshly issued tokens do not fail iat validation.
### Security
* Update urllib3 to 2.8.0 to address security advisories.
* Update PyJWT to 2.15.0 to address security advisories.
