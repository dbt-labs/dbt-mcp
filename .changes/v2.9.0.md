## v2.9.0 - 2026-10-27
### Enhancement or New Feature
* Add dbt Mesh discovery to the Discovery toolset: a new search_public_mesh_models tool (multi-project configurations only) that finds public dbt Mesh models across the configured producer projects, confirms the producer project identity needed to construct a cross-project ref and dependencies.yml entry for each, and answers whether a given warehouse relation is already published as a public model
* Support Python 3.14. Unit tests now run on Python 3.12, 3.13 and 3.14 in CI.
### Under the Hood
* Replace the private `mcp.shared._httpx_utils` import with a local HTTP client factory for remote MCP connections.
* Run deptry in the pre-commit checks to fail on undeclared direct dependencies
* Use the uv version pinned in .tool-versions for CI and release builds.
* Add Paul Yang and Patrick Yost as code owners
* Bump certifi to 2026.7.22 in the lockfiles
### Bug Fix
* Kill the dbt subprocess when a dbt CLI or dbt-codegen tool call times out, instead of leaving it running in the background.
* Fix get_column_lineage always uppercasing the column name
* Apply the show tool row limit unless the SQL has a LIMIT clause, instead of whenever "limit" appears anywhere in it, such as in a credit_limit column or a comment
* Run dbt CLI and dbt-codegen commands off the event loop, so the server keeps answering other requests, health checks included, while a dbt command runs.
